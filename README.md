# Hollowfall
Mod de terror psicológico para Minecraft Java 1.21.1 (NeoForge).

## Compilar sin instalar Java
1. Sube esta carpeta a un repositorio de GitHub.
2. En la pestaña Actions corre "Build Hollowfall".
3. Descarga el artefacto `hollowfall-jar` y copia el .jar a la carpeta mods de tu instancia NeoForge 1.21.1.
